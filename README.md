# Woningen

Mobiele app van de aankoopmakelaar van Frank: Funda-aanbod binnen ongeveer een uur rijden van Amsterdam, gescoord op zijn puntensysteem.

- `index.html`, `sw.js`, `manifest.webmanifest`, iconen: de app (statisch, GitHub Pages).
- `data.json` en `engine.js`: worden elke ochtend door de geplande taak "Aankoopmakelaar dagelijkse scan" bijgewerkt (via `am-cli.js export`). Niet met de hand bewerken.
- Beelden: Funda-foto's en PDOK-luchtfoto's met kadastrale perceelgrenzen.
